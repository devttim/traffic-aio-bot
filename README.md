# traffic-aio-bot


## 📌 Описание

Проект построен на **Aiogram** и разбит на модули по зонам ответственности.

> ⚠️ **Важно:** Вся **внутренняя логика была удалена**. Ранее за проектом был закреплён разработчик, написавший некачественный и трудночитаемый код.  
> В целях безопасности и удобства дальнейшей разработки, логика была полностью вырезана.  
> Оставлена только структура и внешний интерфейс — проект передаётся в виде подготовленного шаблона для нормальной реализации.

## Что реализовано

- Чистая архитектура проекта
- Модули клавиатур, middleware и состояний
- Конфигурационный файл с шаблонными значениями
- Заготовленные обработчики без логики

## Что необходимо сделать

- Реализовать бизнес-логику по задачам, балансу, подписке и т.д.
